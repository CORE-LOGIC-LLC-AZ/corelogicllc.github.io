# Core Logic LLC Static Website

Simple static website for **Core Logic LLC**, focused on software and app development services.

## Files

- `index.html` - Main one-page site.
- `assets/css/styles.css` - Site styles.
- `assets/icons/corelogic-icon.svg` - Active brand icon and favicon (attached style).
- `assets/icons/corelogic-logo.svg` - Full logo lockup used in the header.

## Run locally

```bash
cd /home/kamal-bahadur-nextiva-com/git/corelogicllc.github.io
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173` in your browser.
