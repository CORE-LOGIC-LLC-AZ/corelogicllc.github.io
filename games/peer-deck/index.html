Built for real-world gatherings

True offline autonomy

Fully operational in dead-zones, airplanes, subways, or remote trips — no cellular data, Wi‑Fi router, or online account required.

Hardware-to-hardware

Nearby devices discover each other automatically over Apple's Multipeer Connectivity framework using local Wi‑Fi and Bluetooth.

Premium card-table UX

A dark, tactile interface built natively with SwiftUI — low-latency sync, haptic feedback, and smooth in-person play.

How it works

Host a table

Tap Host Table on one device to start a session and share a room code.

Join locally

Other players tap Join Table, pick a nearby host, and enter the code.

Play in sync

The host selects a game module and every device stays synchronized for the round.

Launch game: 28 (Thuruppu)

Trick-taking · 4, 6, or 8 players

The first supported module is the classic South Asian card game 28. Players sit in partnerships, bid on tricks, and set a hidden trump suit. The round dealer rotates each hand; bidding opens at the seat after the dealer.

  • 4, 6, or 8 players at the same table
  • Host-authoritative state sync for fair, in-person play
  • More game modules planned — one app, many tables

Get started

  1. Tap Host Table on one device to start a session
  2. Other players tap Join Table to find nearby hosts
  3. Enter the room code, pick a game, and play together in sync
