# CaptionBake downloads

Public installers for [CaptionBake](../index.html).

Copy signed/notarized DMGs from the CaptionBake repo `release-artifacts/` folder:

- `CaptionBake-<version>-macos-arm64.dmg` (Apple Silicon)
- matching `.sha256` file
- update `SHA256SUMS.txt` and `../config.js`

Intel (x86_64) builds are not published. See CaptionBake repo `docs/RELEASE.md`.
