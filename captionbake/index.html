Local HTTP API Pro

Automate caption burn-in or caption-free MP4 convert from Final Cut, a shell script, or any tool that can send HTTP. The server runs only while CaptionBake is open, and only on your Mac (127.0.0.1). Requires CaptionBake Pro.

1. Enable the server

  1. Open CaptionBake.
  2. Click the gear icon in the header to open Settings.
  3. Turn on Enable HTTP server (Pro license required).
  4. Confirm the port (default 18765). Change it if something else already uses that port.

The server listens at http://127.0.0.1:<port>. It stops when you turn the toggle off or quit the app. Preferences (enabled + port) are remembered for next launch.

2. Style first (optional)

Tune the Style panel in the app as usual. Exports use those live settings unless your request overrides individual fields. You can also read the current non-default style over HTTP.

3. Export with POST /export

Send a JSON body with these fields:

  • inputVideo — absolute path to a local video file (required)
  • exportedVideo — absolute path for the output file (required; must be .mp4; if you omit the extension, .mp4 is appended)
  • caption — absolute path to a local caption file (optional; SRT, VTT, SBV, ASS/SSA, ITT/TTML, …). Omit to convert video to MP4 without burn-in.

Any other Style panel fields are optional and override the live UI for that export only (same names as in the app / GET response): fontFamily, fontSize, bold, italic, textColor, alignment, offsetYPercent, wordHighlightEnabled, and so on.

Sample: basic export

curl -X POST http://127.0.0.1:18765/export \
  -H 'Content-Type: application/json' \
  -d '{
    "caption": "/Users/you/Movies/talk.srt",
    "inputVideo": "/Users/you/Movies/talk.mov",
    "exportedVideo": "/Users/you/Movies/talk_captioned.mp4"
  }'

Sample: convert video only (no captions)

curl -X POST http://127.0.0.1:18765/export \
  -H 'Content-Type: application/json' \
  -d '{
    "inputVideo": "/Users/you/Movies/clip.mov",
    "exportedVideo": "/Users/you/Movies/clip_converted.mp4"
  }'

Sample: export with style overrides

curl -X POST http://127.0.0.1:18765/export \
  -H 'Content-Type: application/json' \
  -d '{
    "caption": "/Users/you/Movies/talk.srt",
    "inputVideo": "/Users/you/Movies/talk.mov",
    "exportedVideo": "/Users/you/Movies/out/talk_captioned",
    "fontSize": 56,
    "textColor": "#FFFFFF",
    "alignment": "bottom-center",
    "bold": true,
    "strokeWidth": 3
  }'

In the example above, exportedVideo has no extension, so CaptionBake writes talk_captioned.mp4.

Success response

{
  "ok": true,
  "output": "/Users/you/Movies/out/talk_captioned.mp4"
}

Error response

{
  "ok": false,
  "error": "caption not found: /Users/you/Movies/missing.srt"
}

Common status codes: 400 validation, 404 missing file, 409 another export already running, 500 export failure.

4. Read style with GET /settings

Returns only Style panel fields that differ from CaptionBake defaults — using the same attribute names accepted by POST /export. Useful for cloning your current look into a script. 

curl http://127.0.0.1:18765/settings

Example when you’ve changed a few controls:

{
  "fontSize": 56,
  "alignment": "top-center",
  "bold": true,
  "textColor": "#FFE566"
}

If everything is still at defaults, you get an empty object: {}.

Sample: fetch settings, then export

# Capture current non-default style from the app
STYLE=$(curl -s http://127.0.0.1:18765/settings)

# Merge paths + style into one POST body (requires jq)
curl -X POST http://127.0.0.1:18765/export \
  -H 'Content-Type: application/json' \
  -d "$(jq -n \
    --argjson style "$STYLE" \
    --arg caption "/Users/you/Movies/talk.srt" \
    --arg inputVideo "/Users/you/Movies/talk.mov" \
    --arg exportedVideo "/Users/you/Movies/talk_captioned.mp4" \
    '$style + {
      caption: $caption,
      inputVideo: $inputVideo,
      exportedVideo: $exportedVideo
    }')"

Notes

  • Bind address is localhost only — not reachable from other machines on your network.
  • Paths must be absolute paths on the same Mac running CaptionBake.
  • One export at a time; wait for the previous request to finish.
  • alignment values match the Style panel: bottom-center, top-left, center, etc.
  • wordHighlightEnabled is an experimental ASR feature. On-device Whisper can mis-hear or mistime words, and the first run downloads a model (~142 MB of extra disk). Expect longer exports when it is enabled.
